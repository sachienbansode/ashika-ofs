Bid book

How allocation works. Bids at or above the cut-off price are considered for allotment; retail bids may be placed at cut-off price and are eligible for the discount, if any, announced by the seller. Unallotted funds are released after the settlement of the OFS.
CSV columns: code, ucc, name, pan, mobile, email, status (Active / Blocked), cp code, custody code. UCC, CP code and custody code feed the exchange bid file — leave UCC blank and the trading code is used. Codes are matched case-insensitively; re-importing an existing code updates that row.
CSV columns: symbol, company, isin, floor, cut off price, tick, lot, hni open, hni close, retail open, retail close (all YYYY-MM-DDTHH:MM), discount, cutoff (Y/N), status (Auto / Open / Closed / Upcoming). Day 1 is normally the HNI window and day 2 the retail window — a client picks which one to bid under on the ticket, and only an open window is selectable. Auto derives the status from those windows; the daily cut-off time still applies on top.
CSV columns: code, margin. Any of margin, available margin, limit, available limit is picked up as the amount, and the row is matched on trading code or UCC. Margin is checked across all of a client's live bids, and clients see their free margin on the bid ticket. A client whose margin is ₹0 cannot place any bid at all. You can also type straight into the Available margin cell, or use Edit on any row to set, add or deduct an amount.

Exchange bid file

OFS Symbol · Category · Client/CP Code · UCC · Custody Code · Qty · Price · Margin Type · Bid Id · Action Code
Rows carry the client's UCC from the client master (the trading code is used when UCC is blank), Bid Id 0 and action code N for a fresh upload. Category is RI for a retail price bid, RIC for a retail cut-off bid and NII for an HNI bid — all three codes, the margin type and the price used for cut-off bids are set under Settings.

Step 1 — import the allotment file

The file the exchange returns after allocation
Accepts .xlsx or .csv. Needed columns: a client column (UCC, client code or Client/CP code), symbol, allotted qty and allotted price. Extra columns are ignored, and rows are matched back to the bid on trading code or UCC. A client with zero allotted quantity is treated as not allotted and gets no email.

Step 2 — email the allotted clients

Placeholders: {name} {code} {ucc} {symbol} {company} {bidqty} {bidprice} {allotqty} {allotprice} {allotvalue} {refund} {ref} {date} {table}. {table} prints every allotted line for that client, so one email covers a client with several scrips.
Send all opens each message in your own mail program (Outlook and the like) with the address, subject and body already filled — you press send. For a large batch use .eml files (drag them into Outlook's outbox) or the mail-merge CSV with Word or your bulk-mail tool. Nothing leaves this page on its own; there is no mail server behind it.
